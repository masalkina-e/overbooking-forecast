# Овербукинг в сети отелей: прогнозирование отмены бронирования

## Бизнес-задача

Оценить возможность использования модели машинного обучения для прогнозирования вероятности отмены бронирования.

Для отеля такой прогноз может использоваться как дополнительный инструмент при планировании загрузки и принятии решений по овербукингу.

## Что сделано

- проведён первичный обзор данных;
- рассчитана доля отменённых бронирований;
- обработаны пропуски;
- удалены полные дубликаты;
- подготовлены признаки для анализа;
- проведён описательный и диагностический анализ;
- построена логистическая регрессия;
- рассчитана вероятность отмены бронирования;
- оценено качество модели на тестовой выборке;
- сформулированы бизнес-выводы и ограничения.

## Ключевые результаты

- В исходном датасете — 119 390 бронирований.
- После удаления полных дубликатов — 87 396 наблюдений.
- Доля отменённых бронирований в исходных данных — около 37%.
- В модели использованы признаки, которые доступны до момента заселения: срок до заезда, длительность проживания, состав гостей, история отмен и бронирований, изменения бронирования, стоимость, дополнительные запросы и другие характеристики.
- Логистическая регрессия позволяет получить не только класс, но и вероятность отмены через `predict_proba`.

## Важный бизнес-вывод

Модель можно использовать как учебный прототип для оценки риска отмены бронирования. При этом одного показателя Accuracy недостаточно, чтобы автоматически определять объём овербукинга.

Для полноценного бизнес-решения необходимо дополнительно учитывать вместимость отеля, стоимость непроданного номера, стоимость размещения клиента в другом отеле, допустимый уровень риска и правила работы с конкретным сегментом клиентов.

Поэтому результат проекта — инструмент для оценки вероятности отмены, а не готовый алгоритм автоматического увеличения числа бронирований.

## Стек

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Как запустить

1. Скачать репозиторий.
2. Установить зависимости из `requirements.txt`.
3. Открыть `notebooks/overbooking_forecast.ipynb`.
4. Выполнить ячейки последовательно.

## Ограничения проекта

- Данные содержат исторические бронирования за 2015–2017 годы.
- Дубликаты удаляются как полные строки, поэтому часть исходных записей не используется в моделировании.
- Модель является учебным прототипом и не учитывает экономику конкретного решения по овербукингу.
- В проекте не рассчитывается оптимальное количество дополнительных бронирований.
